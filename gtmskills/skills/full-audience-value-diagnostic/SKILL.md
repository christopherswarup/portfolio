# Full-Audience Value Diagnostic

"Marketing = lead factory" is the default framing in most revenue orgs, and it's incomplete by design — it only counts the value delivered to one audience (prospective buyers) and ignores the rest.

## Inputs to gather

**Required:**
- A list of marketing's recent activity — programs, content, enablement work, events — even a rough quarter-in-review list is enough

**Helpful, not blocking:**
- The specific challenge being raised (a budget cut proposal, a headcount review, a board question) and who's raising it
- Any existing pipeline/lead metrics already being cited against marketing, so the counter-framing directly addresses them rather than talking past them

**If none of this is available:** ask *"what did marketing actually do last quarter, in plain terms — not the metrics, just the activity?"* The audience map builds naturally once real activity is on the table.

## The seven audiences marketing actually serves

| Audience | Value delivered | Common metric blind spot |
|---|---|---|
| **Prospective buyers** | Education, trust-building, comparison content | The only audience most orgs measure |
| **Existing customers** | Retention content, expansion messaging, community | Rarely tied back to marketing at all — usually credited to CS |
| **Sales** | Enablement assets, talk tracks, deal-support content | Measured as "requests fulfilled," not deal impact |
| **Product** | Market insight, competitive intelligence, voice-of-customer | Almost never measured or credited |
| **Executives** | Market narrative, board-ready positioning, category framing | Invisible in pipeline reports entirely |
| **Employees** | Internal brand, culture reinforcement, recruiting support | Not typically considered "marketing" output at all |
| **Partners / third-party influencers** | Co-marketing, analyst relations, community advocacy | Usually bucketed as a side project, not core value |

## Why this matters

When marketing is evaluated on pipeline alone, every dollar spent on sales enablement, retention content, or executive narrative reads as "waste" because it doesn't show up in the one metric being tracked. This produces two bad outcomes: marketing over-indexes on lead-gen activity to protect its budget, and the org loses the enablement/retention/insight value that a lead-gen-only marketing function can't fully replace.

## How to apply it

1. **Map current marketing output against all seven audiences** — not just prospective buyers. Most orgs will find real activity happening for 4-5 audiences that's currently unmeasured and uncredited.
2. **Assign a value type per audience** — content, market insight, enablement, brand equity, references/proof, talent-brand signal, co-marketing reach. Don't force everything into a pipeline-dollar equivalent; some of this is legitimately not a pipeline metric.
3. **Use this to defend or restructure budget** — when marketing's role is challenged as "just lead-gen," this is the counter-framework: show where value is landing across the other six audiences, with evidence, not a hand-wave.
4. **Don't let this become an excuse.** This is a broadening tool, not a way to dodge accountability for pipeline where pipeline *is* the stated goal — use it alongside a metrics ladder (see `gtm-metrics-architect`), not instead of one.

## Output format

- **Audience-by-audience value map** — what's currently being delivered to each of the seven, with evidence
- **Unmeasured/uncredited value found** — activity happening that isn't showing up in current reporting
- **Recommended framing** for a budget conversation or strategy doc that reflects the full picture, not pipeline alone
